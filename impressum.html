Zweck der Datenverarbeitung

Die App "IndoorCO2Map Data Collector" dient der Erhebung und Analyse von CO₂-Messungen in Innenräumen und während der Nutzung öffentlicher Verkehrsmittel zu wissenschaftlichen Forschungszwecken. Diese Daten werden genutzt, um ein besseres Verständnis von CO₂-Konzentrationen in öffentlich zugänglichen Innenräumen und Verkehrsmitteln zu ermöglichen und somit zur Verbesserung des öffentlichen Wissens über Innenraumluftqualität beizutragen.

Erhobene Daten

Die folgenden Daten werden von der App erhoben und gespeichert:

Allgemeine Daten (für alle Messungen):

  • Versionsnummer der App
  • Zeitpunkt des Messbeginns
  • Gemessene CO₂-Werte mit Zeitstempel
  • Benutzerdefinierte Notizen (sofern eingegeben)
  • (Geplant) Eine Signatur, die bestätigt, dass die Daten mit der App gesendet wurden

Gebäudemessungen (Building Measurement):

  • Offene Fenster/Türen: Ja/Nein
  • Vorhandensein eines Belüftungssystems: Ja/Nein
  • Breitengrad und Längengrad des gemessenen Standorts
  • Name, ID und Typ des Standorts (basierend auf OpenStreetMap)
  • Zufällig generierte ID, die gleich bleibt, solange derselbe Sensor mit demselben Telefon verwendet wird und die App nicht neu installiert wird (ermöglicht das Löschen vorheriger Messungen bei Fehlern)

Transitmessungen (Transit Measurement):

  • Name, ID und Typ des Startorts (basierend auf OpenStreetMap)
  • Name, ID und Typ des Zielorts (basierend auf OpenStreetMap)
  • Name, ID und Typ der verwendeten Transitlinie (basierend auf OpenStreetMap)
  • GPS-Koordinaten bei jedem neuen Messpunkt
  • Zufällig generierte ID, die für jede Messung unterschiedlich ist (mit Option zur Änderung zu einer persistenten ID in zukünftigen Versionen)

Purpose of Data Processing

The "IndoorCO2Map Data Collector" app is designed to collect and analyze CO₂ measurements in indoor environments and during public transport use for scientific research purposes. This data is used to enhance the understanding of CO₂ concentrations in publicly accessible indoor environments and transit systems, contributing to improved knowledge about indoor air quality.

Collected Data

The following data is collected and stored by the app:

General Data (common for all measurements):

  • The version number of the app you are using
  • The time when the measurement was started
  • The CO₂ values you measured, including a timestamp for each data point
  • Custom notes you entered (if any)
  • (Planned) A signature confirming that the data is sent using the app

Building Measurements:

  • Are there open windows/doors: Yes/No
  • Is there a ventilation system: Yes/No
  • The latitude and longitude of the measured location
  • The OpenStreetMap Name, ID, and Type of the location
  • A randomly generated ID which remains the same as long as you use the same sensor with the same phone and do not reinstall the app (this enables deleting previous measurements if you made a mistake)

Transit Measurements:

  • The OpenStreetMap Name, ID, and Type of the Start of your Journey
  • The OpenStreetMap Name, ID, and Type of the Destination of your Journey
  • The OpenStreetMap Name, ID, and Type of the Transit Line you used
  • The GPS coordinates of your position each time a new data point is added to the measurement
  • A randomly generated ID which is different for each measurement (an option to change this to a persistent ID will be added in later versions)
