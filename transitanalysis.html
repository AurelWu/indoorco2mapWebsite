i Every journey still counts, but each transit line carries the same total weight no matter how often it was measured. A journey on a line with 50 measurements counts one fiftieth as much as a journey on a line measured only once.

This stops one frequently measured line from dominating a group. Unlike Line (journeys averaged), it keeps the spread between individual journeys instead of collapsing each line to a single number.

i Keeps only the transit lines that appear in every group, so each group describes the same set of lines instead of a different one. That way a difference between groups reflects the thing you filtered on, rather than one group simply happening to contain busier or better-ventilated lines.

Matching works at the level of the line (the OSM route relation) — not the individual stations. Two journeys on the same line can still cover different stretches of the route, so trip length and which section was travelled continue to play a role.
